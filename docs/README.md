# Skyline.DataMiner.Utils.UserDefinedApiToolkit

The User-Defined API Toolkit provides an attribute-based way to implement REST-like APIs in
DataMiner Automation scripts. Controllers use familiar route and HTTP method attributes, while the
toolkit handles route selection, parameter binding, dependency injection, typed results, and
optional OpenAPI generation.

## Guides

- [Getting started](getting-started.md) - Install the package and create your first API.
- [Controllers and routing](controllers-and-routing.md) - Define controllers, routes, and action
  parameters.
- [Configuration and responses](configuration-and-responses.md) - Configure dependency injection,
  converters, and response results.
- [Build and packaging](build-and-packaging.md) - Generate OpenAPI documents and package installer
  metadata.
- [Troubleshooting](troubleshooting.md) - Diagnose common configuration and runtime errors.
